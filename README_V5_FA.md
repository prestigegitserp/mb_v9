# نسخهٔ ۵ — توسعهٔ پژوهشی

مبنا نسخهٔ ۴٫۲ منتشرشده روی `v4`، با commit پایهٔ `3e8bd23024a4c2f934a934695a86b89f737d5927` است. شاخهٔ مستقل `v5-development` ساخته شده است. طبق درخواست، تغییرات V5 هنوز **commit یا merge نشده‌اند**؛ بنابراین صرفاً pull کردن شاخهٔ remote فعلاً کد V5 را دریافت نمی‌کند. هیچ ref قدیمی تغییر نمی‌کند.

ورودی مستقل `run_v5.py` است. در working tree این شاخه، `run_v9.py` نیز به‌صورت پیش‌فرض نسخهٔ ۵ را اجرا می‌کند؛ `--code-version 4`، `3` و `2` رفتار نسخهٔ انتخاب‌شده را نگه می‌دارند. تمام فایل‌های قدیمی به‌جز dispatcher و `VERSION` محافظت شده‌اند. `python verify_v5.py` این موضوع را با SHA-256 بررسی می‌کند.

پیاده‌سازی شامل هفت روش، کنترل‌های ابلیشن، تنظیم قوی‌تر رقبا، گزارش صحت بازتولید مقاله، تخصیص صریح CUDA/CPU، ذخیرهٔ موقت گراف در RAM/SSD، Excel با فهرست منابع، CSV کامل و شکل‌های PNG/PDF/SVG است. ادعای بازتولید همهٔ امتیازهای مقاله یا تضمین پذیرش Q1 وجود ندارد.

- [اجرای مرحله‌به‌مرحلهٔ مقاله](docs/V5_PAPER_WORKFLOW_FA.md)
- [یافته‌های واقعی، نتایج منفی و محدودیت‌ها](docs/V5_REVIEW_FA.md)
- [مکانیسم هفت روش و آزمون ابطال](docs/V5_METHODS_FA.md)
- `docs/v5_evidence/`: تنظیمات و نتایج تمام ۳۵ آموزش تازهٔ validation، سورس‌های منجمد زمان آن‌ها، ممیزی فایل‌های ارسالی و آزمون‌های حافظه.

برای شروع پس از در دسترس قرار گرفتن تغییرات روی checkout خودتان:

```bash
python -m pip install -r requirements_v5.txt
python verify_v5.py
python paper_v5.py --phase plan --dataset ml-100k --output ./paper_v5
```

ابتدا راهنما و تعداد fitهای `plan` را بخوانید. `smoke` آزمایش مقاله نیست. مرحلهٔ `scan` در launcher پیش از TEST متوقف می‌شود؛ `final` برندگان همان پوشه و همان تنظیمات را اجرا می‌کند. اجرای `report` و `replot_v5.py` به آموزش مجدد نیاز ندارد.
