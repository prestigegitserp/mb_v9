# نسخهٔ ۵٫۲ — هدف دقت با معیار قابل حسابرسی

نسخهٔ پنجم با سورس V5.2 روی شاخهٔ انتشار `v5` و شاخهٔ توسعهٔ `v5-development` ارائه می‌شود؛ کار V5.2 در `v5.2-development` نیز محفوظ است. با اجازهٔ جدید کاربر، محدودیت قبلیِ بدون commit/merge برداشته شد. پایهٔ سورس، tree کامل V5 به شناسهٔ 99f8b50952101a13be67873a5dce3872c033b327 است و فایل‌های آن حفظ شده‌اند.

تمام فایل‌های V5 و قدیمی‌تر دست‌نخورده‌اند. کد تازه در v52/ و ورودی مستقل run_v5_2.py است. run_v9.py همچنان رفتار V5 را دارد؛ برای اجرای V5.2 از ورودی و launcher جدید استفاده کنید.

## وضعیت واقعی

بررسی اجرایی تازه: هر۳۷ تست اختصاصی V5.2 و کل مخزن با۳۵۰ موفق /۳ skipped روی CPU گذشته‌اند. بررسی واقعی، یک اشکال مسیر auxiliary صفر را نیز آشکار کرد که پیش از ادغام رفع شد. جزئیات محیط و نتایج در docs/v52_evidence/RUNTIME_VALIDATION.json است. آموزش اصلی MovieLens، RMSE تازه و CUDA واقعی **اجرا یا تأیید نشده‌اند**؛ عبور از0.87 هنوز نامعلوم است. شواهد و49 تست قبلی V5 به‌عنوان نتیجهٔ دقت V5.2 معرفی نمی‌شوند.

بررسی نحوی و تبدیل ایستای هر۴۰ فایل Python با Brython بدون خطا انجام شد؛ این بررسی، اجرای CPython یا تست PyTorch نیست. جزئیات در V52_BUILD_STATUS.json و docs/v52_evidence/STATIC_CHECKS.json ثبت شده‌اند.

## اصلاحات

- خطای overwrite روش۵: مقدار L2=0 انتخاب‌شده در V5 در شرط بعدی دوباره10 می‌شد؛ پیش‌فرض V5.2 اکنون صفر می‌ماند.
- decoder پهن با encoder مشترک، مستقل از تنگنای K مسیر هندسی؛ همراه کنترل decoder-only و ابلیشن.
- انتخاب فعال‌ساز، LayerNorm، تجمیع history و ترکیب loss ماسک‌شده/بازسازی مشاهده‌شدهٔ TRAIN؛ همه با config و validation، بدون انتخاب بر اساس TEST.
- AEMC-NE مستقل با کنترل ReLU/sigmoid/tanh، مقداردهی اولیهٔ identity-transfer و full/item-minibatch Adam؛ هیچ‌کدام به‌عنوان جزئیات تأییدشدهٔ کد نویسنده جا زده نمی‌شوند.
- پروتکل پیش‌فرض MovieLens در launcher نسبت85.5/4.5/10 دارد. روش۷ در این مقایسه point-only است؛ احتمال را با validation اضافه نمی‌آموزد.
- سیاست checkpoint مبتنی بر validation برای MBMF با تغییر پروتکل split ناخواسته به سیاست training-objective تبدیل نمی‌شود.
- freeze تنظیمات baselineها و عضویت TEST تقویت شده؛ ارزیاب هدف، آرشیو واقعی و مقایسهٔ کامل را کنترل می‌کند.
